# AgriSense Government Scheme RAG Document Pack

This folder is the starter corpus structure for the AgriSense farmer-government-scheme RAG.

IMPORTANT: The URLs in `sources_manifest.csv` are official/authoritative sources identified during research on 27 Aug 2026. The environment used to prepare this pack could not directly download external PDFs, so the PDF folders are intentionally left ready for the files. Do not replace these sources with random blogs.

Recommended ingestion order:
1. PM-KISAN
2. PMFBY
3. KCC
4. PMKSY
5. Soil Health Card
6. Agricultural Mechanization (SMAM)
7. Agriculture Infrastructure Fund (AIF)
8. RKVY
9. Uttar Pradesh official agriculture schemes

After downloading, put the PDFs in the matching folders and run your ingestion pipeline.
